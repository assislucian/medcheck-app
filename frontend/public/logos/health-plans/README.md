# Logos dos Planos de Saúde

Este diretório contém as logos dos planos de saúde suportados pelo MedCheck.

## Arquivos necessários:

- `unimed-new.svg` ou `unimed-new.png` - Logo da Unimed
- `hapvida-new.svg` ou `hapvida-new.png` - Logo da Hapvida  
- `bradesco-new.svg` ou `bradesco-new.png` - Logo do Bradesco Saúde
- `sulamerica-new.svg` ou `sulamerica-new.png` - Logo da SulAmérica
- `amil-new.svg` ou `amil-new.png` - Logo da Amil

## Especificações recomendadas:

- **Formato**: SVG (preferido) ou PNG com fundo transparente
- **Tamanho**: 200x200px (ou proporção quadrada)
- **Resolução**: Alta qualidade para displays Retina
- **Peso**: Otimizado para web (SVG < 10KB, PNG < 50KB)

## Arquivos temporários criados:

✅ Placeholders SVG foram criados para demonstração
🔄 Substitua pelos arquivos oficiais das operadoras quando disponível

## Fallback:

Se uma logo não estiver disponível, o sistema automaticamente exibirá um ícone de fallback baseado no plano de saúde.
