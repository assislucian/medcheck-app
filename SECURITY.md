# Política de Segurança

## Versões Suportadas

| Versão | Suporte          |
| ------ | ---------------- |
| 2.x.x  | ✅ Suportada     |
| 1.x.x  | ⚠️ Limitado      |
| < 1.0  | ❌ Não suportada |

## Relatando Vulnerabilidades

### Para Vulnerabilidades Críticas

**Não** abra issues públicas. Entre em contato:

- Email: security@medcheck.com.br
- Resposta: 24-48 horas

### Para Vulnerabilidades de Baixo Risco

1. Abra uma issue com label `security`
2. Forneça informações detalhadas
3. Aguarde análise da equipe

## Informações Necessárias

- Descrição detalhada da vulnerabilidade
- Passos para reproduzir
- Impacto potencial
- Versão afetada
- Ambiente (dev/staging/prod)

## Práticas de Segurança

- ✅ Autenticação JWT
- ✅ Rate limiting
- ✅ CORS configurado
- ✅ Logs de auditoria
- ✅ Compliance LGPD
